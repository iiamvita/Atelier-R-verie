# Atelier Reverie

Atelier Reverie is a responsive luxury interior design and architectural portfolio website developed to showcase architectural concepts, interior spaces, design collections, and studio services through a visually engaging and user-focused experience.

## Project Overview

This website was designed and developed using modern web development practices, focusing on accessibility, responsive design, Search Engine Optimization (SEO), and performance optimization.

The project demonstrates the use of semantic HTML5, responsive layouts, optimized media assets, and user-centered design principles to create a professional online presence for a fictional architecture and interior design studio.

## Features

- Fully responsive design for desktop, tablet, and mobile devices
- Semantic HTML5 structure
- Optimized image delivery using modern formats
- Fast content delivery through Vercel CDN
- Accessibility-focused design
- Search Engine Optimization (SEO)
- Cross-browser compatibility (Microsoft Edge, Opera, Google Chrome, and Safari)
- Clean and intuitive navigation

## Website Structure

### Home (index.html)
The landing page introduces Atelier Reverie, highlights featured design concepts, and guides visitors throughout the website.

### Studio / The Atelier (studio.html)
Provides information about Atelier Reverie's design philosophy, creative process, and professional approach.

### Architecture (architecture.html)
Presents architectural concepts, structures, and design solutions developed by the studio.

### Interior Design (interior.html)
Highlights interior design projects with a focus on aesthetics, functionality, and spatial planning.

### Collection (collection.html)
Showcases the studio's curated portfolio of design projects and featured works.

### Visit Us / Contact (contact us.html)
Allows visitors and potential clients to connect with the studio for inquiries and consultations.

## CDN Integration & Deployment

The website is deployed using Vercel, which provides a globally distributed Content Delivery Network (CDN). Static assets such as images, CSS, and JavaScript files are delivered through Vercel's edge network to improve loading speed, scalability, and global performance.

The project is connected to GitHub for version control and automatic deployments.
